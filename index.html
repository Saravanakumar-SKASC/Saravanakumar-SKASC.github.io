Phishing Website Detection

Code

Treats accuracy, interpretability and adversarial robustness as joint goals. Six classifiers compared under one reproducible, config-driven protocol on 11,055 websites and 30 features.

  1. Feature pipeline
  2. 6 classifiers
  3. Stacking ensemble
  4. SHAP & LIME
  5. Adversarial attack
  • Leakage-free stacking ensemble (out-of-fold Logistic Regression meta-learner) was the strongest model.
  • Explained every prediction globally and locally with SHAP and LIME; tracked all runs in MLflow.
  • Key finding: flipping a single feature (SSL state) cut XGBoost accuracy from 96.83% to 72.32%, showing headline accuracy hides fragility.
